## 확장 지점

지금 만들지 않지만 나중에 쉽게 들어올 자리.

| 확장 지점 | 열려 있는가 | 나중에 무엇이 들어오나 |
|---|---|---|
| DB 접근이 한 계층에 모임 | | 읽기 분리, 캐시 |
| 외부 호출이 인터페이스 뒤에 있음 | | 교체, 재시도, 서킷 브레이커 |
| 무거워질 처리가 떼어져 있음 | | 큐, 비동기 전환 |
| 설정이 환경변수로 빠짐 | | 환경 추가 |
| 응답 시간을 재고 있음 | | 성능 개선 근거 |
| 나눌 기준 컬럼이 있음 | | 파티셔닝 |
| 모듈 경계가 지켜짐 | | 서비스 분리 |
